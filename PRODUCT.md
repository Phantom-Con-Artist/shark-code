# Shark Code

<!-- impeccable:product-schema 1 -->

## Platform

web

React and TypeScript inside a Tauri desktop app, with a browser preview.

## Users

People building software with coding agents, including newer coders who need understandable change reviews. The user explicitly includes people with ADHD and dyslexia and selected compact editor-style spacing as the default, with a comfortable option available in preferences.

## Product Purpose

Graphify is agent-only infrastructure, with no user-facing graph explorer.

An agent-first coding workspace: lead with conversation while keeping files, direct editing, terminal, dependency exploration and review accessible in the same environment.

## Operating Context

Long coding sessions on desktop. The user explicitly excludes mobile and tablet design work from the current scope. Agents use a shared native workspace authority; Graphify exploration and impact evidence feed into persisted task proposals. A human reviews before applying.

## Capabilities and Constraints

Versioned native edits, recoverable multi-file application, local code graph, ADK execution, streamed task events and persisted sessions are implemented. Language-server semantic refactoring, shell validation tools for models, production runtime packaging and external CLI adapters remain pending. Browser preview cannot execute native agents. Credentials are configured through the backend environment.

## Brand Commitments

Shark Code name and fin mark. Learn layout conventions from VS Code, Cursor and Antigravity without reproducing their interfaces. The user requests a clean, minimalist, organized workbench.

## Product Principles

- Conversation is a primary working surface.
- Keep source and change evidence within reach.
- Show honest state and scope rather than simulated execution.
- Make review understandable before showing detailed code.
- Keep layout and control locations predictable.

## Accessibility & Inclusion

Target WCAG 2.2 AA where practical. Provide keyboard operation, visible focus, adequate contrast, adjustable reading density/text, reduced motion and an optional focus view. These are inclusive controls, not claims to diagnose or treat ADHD or dyslexia; conformance requires broader manual/assistive-technology testing.
