# Workspace

Mode: Operate. Code-first app surface, existing React/Vite/Tauri stack.

Question: What is my agent doing, and what can I inspect or approve next?

User confirmation: conversation-led workspace, file editing and a terminal; compact density default; learn from VS Code, Cursor and Antigravity; minimalist organization, WCAG AA target and cognitive accessibility.

Direction: neutral dark workbench, flat lightness steps, a narrow activity rail, labeled navigation/explorer at left, conversation in the center, source and review at right, terminal below. Retain the Shark mark and mint status hue. No moving or rearranging panes during a task.

First viewport: project context and a useful file tree, conversation with a clear next action, a real source editor alongside it, and a discoverable terminal. Agent-only graph exploration feeds the task review; there is no user-facing graph explorer. Browser state clearly names its limitations.

Signature interaction: a task proposal brings its plain-language impact summary into review, with optional before/after code before applying through the shared backend. Graphify remains internal to agents.

Accessibility: compact controls have at least 24px targets with spacing; comfortable mode increases type/row sizes; keyboard focus, readable contrast and meaningful status text. Focus mode hides secondary panes on request. No unsolicited motion, blinking cursor or automatic scroll while reading history.

References: VS Code user-interface screenshot; Cursor 3 agent tabs screenshot; Antigravity IDE agent composer and artifact screenshot. Research sources in docs/design-references.md. Reference images are research only, not shipped assets.

Current scope correction: desktop only. Do not refine mobile/tablet layouts or make phone/tablet review a completion gate. Preserve basic fallback behavior without spending additional design work there.
